# Enterprise Features

> Source: [https://geminicli.com/docs/cli/enterprise](https://geminicli.com/docs/cli/enterprise)

## Overview

Enterprise features for organizations using Gemini CLI at scale.

## Enterprise Configuration

### SSO Integration
```json
{
  "enterprise": {
    "ssoProvider": "google",
    "domain": "company.com"
  }
}
```

### Centralized Settings
Deploy organization-wide settings.

### Audit Logging
Enable detailed logging of all activities.

## Features

### Access Control
- Role-based permissions
- Team management
- Project isolation

### Compliance
- Data retention policies
- Audit trails
- Privacy controls

### Administration
- Usage monitoring
- Cost management
- Policy enforcement

## For ableton-mcp (Individual Use)

Enterprise features are typically not needed for individual projects. Standard authentication and configuration suffice.
