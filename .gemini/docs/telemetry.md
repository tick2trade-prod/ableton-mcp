# Telemetry

> Source: [https://geminicli.com/docs/cli/telemetry](https://geminicli.com/docs/cli/telemetry)

## Overview

Gemini CLI collects anonymous usage data to improve the product.

## What's Collected

- Feature usage
- Error reports
- Performance metrics
- Model usage patterns

## What's NOT Collected

- Conversation content
- File contents
- Personal information
- API keys

## Disabling Telemetry

### Configuration
```json
{
  "telemetry": false
}
```

### Environment Variable
```bash
export GEMINI_TELEMETRY=false
```

## Privacy

- Data is anonymized
- No PII collected
- Compliant with privacy laws
