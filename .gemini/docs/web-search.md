# Web Search Tool

> Source: [https://geminicli.com/docs/tools/web-search](https://geminicli.com/docs/tools/web-search)

## Overview

Search the web using Google Search.

## Usage

```
> Search for techno sidechain compression techniques
[Returns search results]
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `query` | string | Search query |
| `numResults` | number | Results count |

## Response

Returns list of results with:
- Title
- URL
- Snippet

## ableton-mcp Usage

```
> Search for Ableton Live 12 new features
> Find tutorials on rumble bass synthesis
> Look up MCP server best practices
```
