# Issue and PR Automation

> Source: [https://geminicli.com/docs/issue-and-pr-automation](https://geminicli.com/docs/issue-and-pr-automation)

## Overview

Automated processes for managing issues and pull requests in Gemini CLI.

## Issue Automation

### Labels
- `bug` - Bug reports
- `feature` - Feature requests
- `docs` - Documentation
- `help wanted` - Community help

### Triage
- New issues get `triage` label
- Bot validates issue templates
- Auto-close stale issues

## PR Automation

### CI Checks
- Build verification
- Test suite
- Lint checks
- Type checking

### Auto-merge
- Dependabot updates
- Minor version bumps

## For Contributors

### Issue Template
Use provided templates:
- Bug report
- Feature request
- Question

### PR Template
Include:
- Description
- Testing done
- Breaking changes
