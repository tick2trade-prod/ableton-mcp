# Releases

> Source: [https://geminicli.com/docs/releases](https://geminicli.com/docs/releases)

## Release Cadence

- **Major**: Quarterly
- **Minor**: Monthly
- **Patch**: As needed

## Current Version

Check your version:
```bash
gemini --version
```

## Updating

### NPM
```bash
npm update -g @google/gemini-cli
```

### Homebrew
```bash
brew upgrade gemini-cli
```

## Version History

## Pre-release Versions

### Beta
```bash
npm install -g @google/gemini-cli@beta
```

### Preview
```bash
npm install -g @google/gemini-cli@preview
```
