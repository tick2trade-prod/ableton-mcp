# IDE Integration

> Source: [https://geminicli.com/docs/ide-integration](https://geminicli.com/docs/ide-integration)

## Overview

Connect Gemini CLI to your code editor for enhanced development.

## Supported IDEs

- VS Code
- JetBrains IDEs
- Neovim
- Emacs

## Integration Methods

### Terminal Integration
Use Gemini CLI in integrated terminal.

### Companion Extensions
IDE-specific extensions for deeper integration.

### Editor Commands
Trigger Gemini from editor commands.

## VS Code Integration

### Terminal
1. Open integrated terminal
2. Run `gemini`
3. Use with file context

### Extension
Install Gemini CLI companion extension.

## Antigravity IDE

For this project, we use Antigravity IDE which has native Gemini integration:
- Built-in agent
- MCP support
- File context

See [Antigravity Documentation](../.antigravity/docs/README.md).
