## How to Create the PRs

Since the GitHub CLI (`gh`) is not available, you'll need to create the pull requests manually using the GitHub web interface. Here are two methods:

### Method 1: Use the Direct Links Above
Click on each "Create PR" link above. This will take you directly to GitHub's PR creation page with the branch pre-selected.

### Method 2: Manual Creation
1. Go to https://github.com/tick2trade-prod/ableton-mcp/pulls
2. Click "New pull request"
3. Select the appropriate branch from the dropdown (e.g., `claude/pr-50-rack-chain-tools-01AThBHkouiH1FTYbixGkL9B`)
4. Fill in the PR title and description using the information from this document
5. Click "Create pull request"
