# Agent Manager

> Source: [https://antigravity.google/docs/agent-manager](https://antigravity.google/docs/agent-manager)

## Overview

The Agent Manager provides a centralized view for managing workspaces, conversations, and agent activities.

## Features

### Workspace Management
- Multiple project workspaces
- Switch between projects
- Workspace settings

### Conversation History
- View past conversations
- Resume conversations
- Search history

### Task Overview
- Active tasks
- Task groups
- Implementation plans

## Using Agent Manager

### Accessing
- Click Agent icon in top bar
- Use `Cmd+Shift+A`

### Workspace Operations
- Open workspace
- Close workspace
- Configure settings

### Conversation Management
- Start new conversation
- Continue previous
- Export conversation

## Agent Manager for ableton-mcp

### Workspace Context
The ableton-mcp workspace includes:
- Project files
- MCP server configuration
- GEMINI.md rules
- Workflow definitions

### Quick Actions
- Run test suite
- Check Ableton connection
- Start MCP servers

### Task Tracking
View project tasks:
- Active implementation plans
- In-progress task groups
- Recent conversations
