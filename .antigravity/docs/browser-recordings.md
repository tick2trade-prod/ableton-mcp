# Browser Recordings

> Source: [https://antigravity.google/docs/browser-recordings](https://antigravity.google/docs/browser-recordings)

## Overview

Record browser sessions for documentation and review.

## Recording Features

### Automatic Recording
All browser subagent tasks are recorded automatically.

### Manual Recording
Start/stop recording manually.

### Playback
Review recordings in the IDE.

## Recording Format

Recordings are saved as WebP videos:
```
.antigravity/recordings/
├── sidechain_research.webp
├── roar_docs.webp
└── tutorial_extraction.webp
```

## Usage in ableton-mcp

### Document Research
Record research sessions for later review.

### Create Tutorials
Record how to find information.

### Debug Issues
Review what happened during failed tasks.

## Viewing Recordings

1. Open Artifacts pane
2. Navigate to recordings
3. Select recording to play
4. Use playback controls

## Best Practices

### 1. Name Descriptively
```python
RecordingName="roar_multiband_settings"
```

### 2. Review Important Tasks
Watch recordings of critical research.

### 3. Clean Up Old Recordings
Remove outdated recordings to save space.
