# Chrome Extension

> Source: [https://antigravity.google/docs/chrome-extension](https://antigravity.google/docs/chrome-extension)

## Overview

The Chrome Extension enables integration between Antigravity and Google Chrome.

## Features

### Page Capture
- Capture page content
- Send to agent

### Context Sharing
- Share browser context with agent
- Include in conversations

### Quick Actions
- Send page to agent
- Start task from page

## Installation

1. Install from Chrome Web Store
2. Sign in with same account
3. Enable extension

## Usage

### Send Page to Agent
1. Navigate to page in Chrome
2. Click extension icon
3. Select "Send to Agent"
4. Continue in Antigravity

### Capture for Research
```
Chrome: Browse to tutorial page
Extension: Capture → Send to Agent
Antigravity: Summarize this tutorial
```

## Use Cases for ableton-mcp

### Documentation Capture
Capture Ableton manual pages for reference.

### Tutorial Extraction
Send tutorial pages for agent to extract techniques.

### Research Collection
Gather multiple pages for comprehensive research.
