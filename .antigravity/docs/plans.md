# Plans

> Source: [https://antigravity.google/docs/plans](https://antigravity.google/docs/plans)

## Overview

Antigravity offers different subscription plans with varying features.

## Plan Features

### Free Tier
- Basic agent features
- Limited MCP tools
- Community support

### Pro Tier
- Full agent capabilities
- All MCP tools
- Priority support
- Extended context window

### Enterprise Tier
- Team collaboration
- Custom MCP servers
- SLA guarantees
- On-premise options

## Features for ableton-mcp

For this project, you benefit from:

### MCP Integration
- Multiple MCP servers
- Custom tool development
- Redis integration

### Research Tools
- Web search
- SOTA researcher
- Browser subagent

### Agent Capabilities
- Large context window
- Multi-step tasks
- Agentic workflows
